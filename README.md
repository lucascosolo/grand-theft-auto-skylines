# GTA: Skylines

Step out of the city builder into your own Cities: Skylines city as a GTA-style character: walk,
sprint and fight in first or third person, steal any car, drive, enter every building (each gets
a generated interior), run taxi, paramedic and firefighter jobs for the city, and get chased by
witness-driven police that search, set roadblocks and remember you.

Everything runs inside Cities: Skylines as one mod. Status: in development; see `docs/STATUS.md`.
